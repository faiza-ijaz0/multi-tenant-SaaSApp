# Getting started

## Prerequisites

- Node.js 24+
- pnpm (`corepack enable` or `npm install -g pnpm`)

## Setup

```bash
pnpm install
cp .env.example .env.local   # fill in the values below
pnpm dev
```

App runs at http://localhost:3000.

## Environment variables

Defined in `.env.example` (names only, no real values committed). Real values go in `.env.local`, which is gitignored.

| Variable | Where it comes from |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | `SignalBoard Development` Supabase project → Project Settings → API |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Same page — the `anon`/publishable key |

Both are safe to expose to the browser: Row Level Security, not key secrecy, is what enforces authorization. Never put a service-role key in a `NEXT_PUBLIC_*` variable, and never commit `.env.local`.

## Other checks

```bash
pnpm lint                # eslint
pnpm exec tsc --noEmit   # typecheck (run `pnpm build` at least once first — see note below)
pnpm build               # production build
```

`LayoutProps`/`PageProps` are Next.js-generated types that only exist after `.next/types` has been generated by a `build` or `dev` run — run one of those before a standalone `tsc --noEmit`.
